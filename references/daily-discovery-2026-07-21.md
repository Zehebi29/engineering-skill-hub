- **航空航天/CFD**: 该领域 MCP 生态持续极度稀少。有趣的新苗头：benajaero/rocket-tools（★1，35 aerospace MCP tools）和 vorobjewsen30-max/ansys-mcp-server（★4，Ansys 仿真 MCP），但 Star 过远低于门槛。soljourner/claude-engineering-skills（★39）是通用工程 skill 集含航空航天，但不活跃且 Star < 100。整体该领域 MCP 生态仍是空白为主。
- **机器人/ROS**: 所有真正的机器人 MCP server 和 agent skill 已在 README。新候选要么是研究论文项目（robogen），要么是非物理机器人的 false positive（rf-mcp/Robot Framework），要么 Star 过低。机器人领域 MCP 表已相当饱和（8 个条目），Skills 表也有 3 个条目（robotics-agent-skills ★318、robotics-skills-suite ★258、ros2-engineering-skills ★133）。
- **能源/电力/电池**: "power" 关键词在 Way B 搜索中产生大量 false positive（通用 MCP 工具/框架/客户端），"power system" 精确搜索仅找到已收录的 PowerMCP 和低星候选（dchub-mcp-server ★2、ne_power_grid_mcp_server ★1）。Way D 搜索也受噪音干扰（power 匹配计算能力等语境），真正的能源工程相关的 audio-energy 等 skills Star 极低。该领域 MCP 和 Skills 表仍然只有 PowerMCP（★184）、EnergyPlus-MCP（★104）和 PowerSkills（★55）这 3 个条目。
- **周二领域整体生态稀疏**：三个领域均无新增，航空航天和能源领域连续多周无合格新候选。这符合 skill 中对该领域的评估（航空航天和能源 MCP 生态稀少，机器人表已饱和）。
